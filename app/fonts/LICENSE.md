# Fonts

Self-hosted (no runtime request to a font CDN), latin subset, variable weight:

- **Bodoni Moda** (display: wordmark, product names, prices), by Owen Earl (indestructible type*).
- **Jost** (interface text), by Owen Earl (indestructible type*).
